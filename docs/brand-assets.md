# Athirikya brand assets

- `assets/athirikya-logo.png` is the square browser-tab icon.
- `assets/athirikya-wordmark.png` is the visible website wordmark used in headers and footers.

Visible branding is rendered by the shared stylesheets on the existing header and footer containers. This avoids browser-dependent replacement of normal `<img>` elements through the CSS `content` property.
