Einkaufen im Alltag

So funktioniert ein Wochenmarkt

Auf einem Wochenmarkt kaufen viele Menschen Obst, Gemüse, Brot, Käse, Blumen oder regionale Produkte direkt an einzelnen Ständen.

Was kann man fragen?

  • Kommt das aus der Region?
  • Ist das schon reif?
  • Was kostet ein Kilo?
  • Kann ich ein halbes Kilo bekommen?
  • Darf ich einmal probieren?

Mengen bestellen

Sie können nach Gewicht bestellen, zum Beispiel ein halbes Kilo, 250 Gramm oder einfach eine bestimmte Anzahl. Bei manchen Produkten nennt die Verkäuferin oder der Verkäufer zuerst den Preis für die gewählte Menge.

Bezahlen

Viele Stände akzeptieren Bargeld. Manche bieten inzwischen Kartenzahlung an. Es ist trotzdem sinnvoll, etwas Bargeld dabeizuhaben.

Praktischer Satz

Ich hätte gern ein halbes Kilo von den Pflaumen, bitte.
